# 🎓 Student Management System

A simple Student Management System built using **PHP, MySQL, HTML, CSS, and XAMPP**.

## Features
- Add Student
- View Students
- Search Student
- Delete Student

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- XAMPP
- VS Code

## How to Run
1. Start Apache and MySQL in XAMPP
2. Import `database/student_db.sql`
3. Open `http://localhost/Student-Management-System/`
