# 🎓 Student Management System

A simple **Student Management System** built using **PHP, MySQL, HTML, CSS, XAMPP, and VS Code**.

## 🚀 Features

- ➕ Add Student
- 📋 View Students
- 🔍 Search Student
- ✏️ Edit / Update Student
- ❌ Delete Student
- 💾 MySQL Database Integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- PHP
- MySQL
- XAMPP
- VS Code

## 📂 Project Structure

```text
Student-Management-System/
│
├── index.php
├── add_student.php
├── view_students.php
├── edit_student.php
├── delete_student.php
├── style.css
└── database/
    └── student_db.sql
```

## ⚙️ How to Run

1. Start **Apache** and **MySQL** in XAMPP.
2. Open **phpMyAdmin**.
3. Create a database named `student_management_system`.
4. Import `database/student_db.sql`.
5. Place the project folder inside `htdocs`.
6. Open the browser and run:

```text
http://localhost/Student-Management-System/
```
